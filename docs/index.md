# Introducció a la Programació amb Python { .hero-title }

Un curs curt i pràctic per a l'optativa de 2n d'ASIX semipresencial. Una classe cada setmana, apunts per a avançar al teu ritme i exercicis que pots **executar ací mateix**, sense instal·lar res.

No cal saber programar. Sí que cal constància: uns 20 minuts de pràctica quasi cada dia valen més que tres hores el diumenge.

## Com funciona

<div class="grid cards two" markdown>

    ---

    S'alterna el torn: una setmana **dimecres** (14:20, torn de matí) i la següent **dijous** (15:15, torn de vesprada). Cada classe avança temari.

## Preguntes freqüents

??? question "He d'anar obligatòriament a classe?"

    No. En semipresencial l'assistència a les tutories col·lectives és voluntària i no puntua, encara que es passa llista. Com que cada setmana és un torn diferent, si només pots vindre a un, segueix les altres sessions amb els apunts i el resum que es penja a Aules.

??? question "Quins coneixements previs necessite?"

    Cap de programació. Només saber moure't per l'ordinador: crear carpetes, guardar fitxers i obrir un terminal.

??? question "Quant de temps he de dedicar-hi?"

    Compta amb 1 o 2 hores per setmana a banda de la classe: llegir, provar els exemples i fer els exercicis.

??? question "Quin programari necessite?"

    Python 3 i l'editor Thonny, gratuïts. Instruccions a [Prepara l'entorn](unitats/entorn.md). Si un dia no tens el teu ordinador, pots provar el codi en aquesta web.

??? question "Sóc de DAW. Em convé aquesta optativa?"

    L'optativa està pensada per a l'alumnat d'ASIX. Si estudies DAW ja treballes aquests continguts, amb més profunditat, al mòdul de Programació. Consulta-ho amb la tutoria o amb direcció d'estudis abans de matricular-t'hi.

??? question "On pregunte els dubtes?"

    Primer al fòrum de dubtes d'Aules: la teua pregunta pot ajudar altres companys, i participar compta per a la nota. Per a temes personals, missatge privat per Aules. Tens una plantilla per a preguntar bé a [Recursos](recursos.md#com-preguntar-al-forum).
